## 메뉴와 공통 푸터

Header와 상단 메뉴는 각 페이지에 직접 있습니다. 항목을 바꿀 때 일곱 페이지와 공통 푸터의 링크·현재 페이지 표시를 함께 확인합니다. 오류 페이지의 단순 Header와 대시보드의 별도 Header도 확인합니다.

푸터는 `partials/footer.html`에서 수정합니다. 각 페이지에서 정상적으로 불러오는지, 로드 실패 시 대체 링크가 표시되는지 확인합니다. 문의 안내는 각 페이지에 직접 들어 있으며 별도 문의 partial은 없습니다.

## 문의폼 변경

1. HTML의 입력 타입·필수 표시·최대 길이·label·오류 영역을 함께 수정합니다.
2. `app.js`의 필드 수집, 검증, 전화번호 처리와 파일 제한을 확인합니다.
3. 새 필드의 오류 요소 ID는 입력 ID에 `-error`를 붙이는 규칙을 따릅니다.
4. 데모 확인 문구와 개인정보 안내가 실제 동작과 일치하는지 확인합니다.
5. 잘못된 입력, 오류 수정, 완료 후 초기화와 키보드 포커스를 확인합니다.

파일 제한은 입력의 `accept` 속성과 JavaScript의 허용 확장자를 함께 바꿉니다. 선택·중복 추가·삭제·최대 개수·개별 및 전체 용량을 확인합니다. 데모에는 전송 기능을 추가하지 않으며 실제 개인정보 대신 예시 값으로 확인합니다.

## 샘플 통계 변경

기간별 JSON은 `meta.source`가 `sample`이어야 합니다. 추이 데이터의 길이와 조회 기간을 맞추고, 문의 합계·문의 페이지 조회수·전환율이 일관되도록 수정합니다. 날짜는 고정된 예시 기간입니다.

표시 형식이나 데이터 구조를 변경하면 JSON과 `dashboard/app.js`를 함께 확인합니다. 빠른 기간 전환, 지표 선택, 빈 배열과 파일 로드 실패도 확인합니다. 실제 기업 통계나 검색어로 교체하지 않습니다.

## 이미지·폰트·스타일

이미지 경로를 바꿀 때 HTML의 `src`와 CSS 참조를 함께 확인합니다. `alt`, `width`, `height`를 유지합니다. 공통 스타일은 여러 페이지에 영향을 주므로 데스크톱과 모바일에서 소개·문의 화면을 함께 확인합니다.

폰트 파일을 배포할 때 [원본 라이선스](../fonts/LICENSE)를 함께 유지합니다. `previews/`는 README용 화면 미리보기이므로 눈에 띄는 화면 변경 후 필요에 따라 갱신합니다.

## 검사

저장소 루트에서 실행합니다.

```sh
python check_demo.py
node --check app.js
node --check dashboard/app.js
git diff --check
```

`check_demo.py`는 HTML 링크·자료의 존재, 이미지 속성, 전송 엔드포인트 부재, 실행 파일의 운영 연동 패턴, 텍스트의 일부 비밀키 패턴, 샘플 데이터 일관성을 확인합니다. 문서에 서비스 이름을 설명하는 것은 허용하지만 비밀키 패턴 검사는 문서에도 적용합니다.

정적 검사는 실제 화면·접근성 전체·모든 종류의 비밀정보를 보장하지 않습니다. 원본 검사 파일과 서버 API 검사는 현재 데모에 포함하지 않으므로 해당 명령을 실행하도록 안내하지 않습니다.

## 화면 확인

- 모든 페이지·이미지·폰트·푸터가 정상적으로 표시되는지 확인합니다.
- 모바일 메뉴, Escape 닫기와 키보드 이동을 확인합니다.
- 폼의 필수값·연락처·이메일·파일 제한·확인 체크박스와 초기화를 확인합니다.
- 통계의 기간·지표 선택, 로딩·빈 데이터·실패 안내를 확인합니다.
- 브라우저 Network에서 문의 제출 요청이나 외부 분석 요청이 발생하지 않는지 확인합니다.
- 좁은 화면에서 이미지·문장·표·폼이 가로로 넘치지 않는지 확인합니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 푸터가 비어 있음 | HTTP 서버 사용 여부, Console·Network, partial 경로 |
| 통계가 표시되지 않음 | 샘플 JSON 요청, 문법, `meta.source`와 화면 데이터 구조 |
| 폼에서 오류 발생 | 입력 ID와 오류 요소 ID, 필드 타입, 공통 스크립트 로드 |
| 하위 경로 배포에서 화면이 깨짐 | `/` 기준 경로를 저장소 루트에서 제공하는지 |
| 수정한 화면이 반영되지 않음 | 배포된 커밋, 캐시, 실제 호스팅 경로 |
