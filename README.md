# Linen Studio — 기업 웹사이트 포트폴리오

실제 기업 웹사이트 개발 경험을 바탕으로 **가상 브랜드와 예시 콘텐츠로 재구성한 데모**입니다. 운영 저장소의 커밋 기록과 실제 회사 자료는 포함하지 않습니다.

## 체험

- 브랜드·서비스·사용자 흐름·공간 소개: 반응형 다중 페이지
- 문의 데모: 필수값·전화번호·이메일 검증, 파일 선택·삭제·드래그 앤 드롭, 접근 가능한 오류 안내
- 통계 데모: 7·30·90일, 지표 전환, SVG 추이 차트, 유입 경로와 검색 성과

문의 입력과 첨부파일은 전송·저장하지 않습니다. 통계는 저장소의 가상 JSON입니다. 실제 회사명·연락처·사진·계약 조건·설비 정보·분석 태그·인증키·서버 API·내부 운영 문서는 포함하지 않습니다.

## 기술과 구현

HTML · CSS · Vanilla JavaScript. 프레임워크와 빌드 단계 없이 동작합니다.

- `app.js`: 공통 partial 로딩, 모바일 메뉴와 Escape 처리, 문의 검증과 파일 선택
- `styles.css`: 반응형 레이아웃, 상태 표시, 모션 감소 설정
- `dashboard/app.js`: 기간·지표 전환, 차트와 표 렌더링, 로드 오류 처리
- `dashboard/sample-*.json`: 기간별 가상 데이터
- `assets/`: 데모 전용 벡터 일러스트

운영 연동 구현은 이 공개 데모 범위에서 제외했습니다. 팀 작업 여부와 실제 담당 범위는 별도 포트폴리오 설명에서 사실에 맞게 명시하세요.

## 실행

```sh
python -m http.server 4173 --bind 127.0.0.1
```

<http://127.0.0.1:4173/>와 <http://127.0.0.1:4173/dashboard/>에서 확인합니다. 공통 HTML을 fetch하므로 `file://` 대신 HTTP 서버를 사용합니다.

## 검사

```sh
python check_demo.py
node --check app.js
node --check dashboard/app.js
```

정적 호스팅은 저장소 루트를 제공해야 합니다. 현재 `/` 기준 링크는 서브경로에 배포하는 GitHub Pages 프로젝트 URL을 지원하지 않습니다.

## 자료와 권리

브랜드·수치·문구는 데모용 예시입니다. 벡터 이미지는 이 데모를 위해 제작했습니다. Pretendard는 원본 저작권 고지와 SIL Open Font License를 `fonts/LICENSE`에 포함했습니다. 저장소 공개는 코드와 디자인에 대한 별도 재사용 라이선스 부여를 뜻하지 않습니다.
